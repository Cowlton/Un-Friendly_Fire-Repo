# Un-Friendly_Fire-Repo
My crazy multiplayer game

This is a chaos multiplayer party game I am developing where you hit your friends with bats, get smushed by boulders, collect cash and run amuck.
It is in its early stages so there is no starting UI You just get straight into playing

All the code in the assets folder except the stuff in the TextMeshPro folder is stuff I have written or added. I have programmed around 48 hours in this project. Unfortunately,
so, my project doesn't completely stop working. I have to have a bunch of unity code in the repo.

Q and A

Q: - How do I play the game / how do I activate local multiplayer?

A: - Go to https://space-cow-code.itch.io/un-friendly-fire, Click Download and press "no thanks just take me to downloads" extract and launch the game.
Once launched Connect a controller and start moving around. Because I am still in the early stages of development just move around with a different controller to connect another player


Q: - What are the controls?
A: - "A" and "B" are using item "Y" and "X" are run, and the Right trigger is to attack (you can also use "WASD" to move "Space" to attack "Shift" to use item and "Ctrl" to run).


Q: - Why does 'Adding my project to a repository' add so much code?
A: - I was struggling to add my code to a git repository since I was using unity building a project that already had a bit of code.
I was doing this while also adding more code so by the time I got it to work the commit had a ton of code.
